# Figure Folder Rules

Read this file whenever the deck will contain figures, or when `--figures` is passed.

## Resolving the figures folder (`<figures_dir>`)

- If `--figures path/` was given → use that path. Create it if it does not exist.
- Otherwise → `<figures_dir>` = `<output_dir>/<source_basename>-<YYYYMMDD_HHMM>-figures/`.
  Do **not** create yet — create only if the deck will have at least one figure (decided in step 10).

The `<YYYYMMDD_HHMM>` value comes from step 9b (`date +%Y%m%d_%H%M`). Reuse the same value in step 11 for BASE so the folder name and YAML/HTML filenames share the same timestamp.

## Scanning pre-existing files (step 9b)

Glob `<figures_dir>` for `*.{jpg,jpeg,png,gif,webp,svg,mmd}` (if the folder already exists). List them — they are available to reference in the deck. Not all files need to be used.

Check for `<figures_dir>/captions.yaml`. If it exists, load it. It maps each filename to `caption` and `alt_text`. Use these values when referencing pre-existing figures.

## Generating figure files (step 10b)

For every figure the deck references that does not already exist as a file:

- **Mermaid diagram:** write source to `<figures_dir>/<descriptive-kebab-name>.mmd` using the Write tool. Use short descriptive filenames (`pipeline-overview.mmd`, `roc-curve.mmd`). Never overwrite a pre-existing file — choose a new name.
- **SVG:** write to `<figures_dir>/<name>.svg` if the LLM generates an SVG inline.
- `.jpg` / `.png`: cannot be generated by the LLM — these must be supplied by the user.

Create `<figures_dir>/` with `mkdir -p` at this point if it does not yet exist and the deck has at least one figure.

## captions.yaml

Write or update `<figures_dir>/captions.yaml` to include an entry for every figure *used* in the deck (pre-existing or newly generated). Do not list files in the folder that the deck does not reference.

```yaml
# captions.yaml
images:
  - file: pipeline-overview.mmd
    caption: "One-sentence figure caption."
    alt_text: "Screen-reader description of what the diagram shows."
  - file: results-chart.png
    caption: "Bar chart comparing accuracy of three methods."
    alt_text: "Bar chart with three grouped bars (DBSCAN, K-means, OPTICS) on the x-axis and accuracy percentage on the y-axis. DBSCAN reaches 94.2%, K-means 91.5%, OPTICS 93.8%."
```

- For pre-existing files already in `captions.yaml`, preserve existing captions unless you have clearly better information.
- `alt_text` on each figure slide in the YAML must match the value recorded here.

## YAML authoring rules

- Use `layout: figure` + `src: <figures_dir>/filename.ext` for **all** figures — raster, SVG, and Mermaid.
- Do **not** use inline `layout: diagram` body for new diagrams — write the source to a `.mmd` file in step 10b instead. (`layout: diagram` with inline body remains valid for backward compatibility only.)
- `alt_text` on each figure slide must match `captions.yaml`.
